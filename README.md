# Dulcetes com o Lula

Site estático responsivo em HTML, CSS e JavaScript. Não precisa de instalação nem de servidor para testar.

## Como visualizar
1. Extraia a pasta do ZIP.
2. Abra `index.html` no navegador.
3. Para publicar, envie a pasta inteira para uma hospedagem estática (por exemplo, Vercel, Netlify ou GitHub Pages).

## Arquivos
- `index.html`: estrutura e seções do site.
- `styles.css`: identidade visual e layout responsivo.
- `app.js`: menu mobile, atualização da prévia, limpar e exportar PNG.
- `assets/foto-base.png`: imagem enviada usada na página inicial.

A colinha é uma ferramenta de anotação pessoal; os campos iniciam vazios e não enviam nem persistem dados. Os links de consulta direcionam a canais públicos do TSE. O projeto se identifica como independente e não oficial.
